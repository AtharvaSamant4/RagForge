## Practical limits

The model is an English sentence encoder. Fixture inspection informed tuning, so these are regression measurements, not blind/generalized accuracy. Candidate labels await actual human review; misses and refusal disagreement remain in the larger candidate set. Quote provenance is checked; semantic truth/entailment and general contradictions are not solved. Timing varies with hardware, batching, cache state and competing work. Concurrent tail latency and per-process model memory are visible in the measurements. Hosted adapters are contract-tested, not live-paid-provider verified. Internet exposure still requires the security hardening listed in SECURITY.md.
